# 한 판 더

게임에서 후배에게 진 뒤 비웃음을 마주한 분노와 자존심을 담은 창작 랩입니다. 화를 박자로 옮기고 다음 경기를 준비하는 이야기로 구성했습니다.

> 비웃음은 짧아 내 연습은 길어
> 한 판 더 가자 내 박자가 들려

## 바로 사용하기

- [피아노 반주 MP3](piano/backing.mp3): 실제 랩 목소리는 포함하지 않은 반주입니다. 10초부터 첫 가사를 시작합니다.
- [랩 리듬·가사 + 피아노 합본 악보 PDF](rap/score.pdf): 4쪽. × 모양 음표는 가사를 말하는 리듬이며 노래 음높이를 뜻하지 않습니다.
- [피아노 반주 악보 PDF](piano/score.pdf): 양손 큰보표, 2쪽.
- [전체 랩 가사](lyrics.txt), [가사 시간표](lyrics.lrc), [구간별 가사 JSON](lyric-cues.json).
- [반주 MIDI](piano/score.mid), [랩 박자 가이드 MIDI](rap/score.mid): 가이드 파일은 우드블록 소리로 가사 타이밍을 표시합니다. 실제 보컬이 아닙니다.
- [합본 MusicXML](rap/score.musicxml), [피아노 MusicXML](piano/score.musicxml): 악보 편집기에서 수정할 수 있습니다.

A단조, 96 BPM, 4/4박자, 32마디입니다. 음악은 80초이며 MP3는 잔향을 포함하여 약 83초입니다.

가사 24줄, 271음절을 리듬 악보에 전부 반영했습니다. 한글 음절에 서양식 가사 연결 하이픈이 생기지 않도록 표기를 적용했습니다. 가사와 음표 사이 여백 및 가사끼리의 간격을 점검했습니다.

## 생성 및 검증 기록

기존에 실제 피아노 악보로 학습한 모델의 A단조 조건 추론에서 오른손 화음과 세기를 생성하고, 랩에 맞춰 직접 설계한 절제된 피아노 리듬과 왼손 근음·5도 패턴을 결합했습니다. 후렴은 반복되며 마지막은 A단조 으뜸화음으로 마무리합니다. 이번 샘플에서 새 모델 학습을 수행한 것은 아닙니다. 랩 가사와 리듬은 이 상황을 위해 새로 작성했으며 랩이나 사진 감정을 학습한 모델이라는 의미가 아닙니다.

- 모델 체크포인트 SHA256: `3ac0e307969432afffe3e7acf6ddb3989d9ff259f54581cb1a52501da7fb0864`
- 사용 프로필: `research-noncommercial`. 학습 데이터와 모델의 이용 조건을 유지합니다. 상업 이용 허가를 의미하지 않습니다.
- 사진에서는 실내에서 웃는 인물을 관찰했습니다. 게임 패배·후배 관계·비웃음의 의미는 사용자가 설명한 상황에서 가져왔습니다. 사진 원본은 이 묶음에 포함하지 않았습니다.
- `verification.json`: MusicXML과 MIDI의 음표·박자·세기 일치, 가사 누락 없음, 끝나지 않는 음표 없음.
- `engraving-verification.json`: 가사 연결 하이픈 0개, 가사 간격 충돌 0쌍.
- `pdf-review/verification.json`: PDF 전 6쪽의 A4 크기와 렌더링 확인. 전 페이지 및 가사 확대 화면을 육안으로 검토했습니다.
- `audio-verification.json`: 렌더링 원본 WAV의 길이·레벨·클리핑 검사. 주관적인 청취 평가를 의미하지 않습니다.
- `provenance.json`: 조건, 시드, 마디별 생성 내역. `source/`에는 생성·검증 스크립트가 있습니다. 재실행에는 OMR 소스와 기존 체크포인트가 필요합니다.

음원 렌더러와 사운드폰트의 저작권 고지는 `audit/`에 포함했습니다. 체크포인트, 학습 데이터 및 사진 원본은 배포 묶음에 포함하지 않았습니다.
