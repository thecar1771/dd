# 오늘도, 나의 자리 — 풍부한 피아노 편곡 및 실제 학습 보고서

최종 코퍼스는 1,832개 악보 파일, 1,123개 작품, 132개 작곡가 그룹, 161,043마디, 2,438,926음표입니다. 기존 1,215개에 실제 수집·검증한 617개를 추가했습니다. 가중치를 처음부터 초기화한 최종 학습 실행은 6에포크를 완료했고, 배포 가중치는 검증 손실로 선택한 6번째 에포크입니다. 합성 악보로 학습량을 부풀리지 않았습니다.

## 곡과 편곡

기존 생성기는 오른손 단선율과 왼손의 고정적인 4분음표 패턴을 강제하여 학습 자료에 있는 화음과 여러 성부가 출력에 반영되지 않았습니다. 새 생성기는 저음·내성·멜로디의 역할을 나누고, 구간별로 반주 밀도와 음형을 바꾸도록 설계했습니다.

장르는 발라드이며, 지치지만 출근하여 일하는 데서 살아 있음을 느끼고 오늘도 최선을 다하겠다는 기존 이야기를 유지했습니다. C장조, 72BPM, 4/4, 32마디입니다. 기존 멜로디의 음높이·시점·길이와 가사 94음절은 보존했습니다. 새 모델은 제한된 화성 후보 안에서 내성 및 왼손 음을 선택했고, 실제 모델 확률을 사용한 선택은 213회입니다. 곡의 구간 구성과 반주 리듬, 화성 후보, 음역, 음량 균형은 작성한 편곡 규칙입니다. 전곡 구조나 감정을 모델이 스스로 학습했다고 주장하지 않습니다.

| 실제 악보 지표 | 기존 | 새 편곡 |
|---|---:|---:|
| 음표 수 | 221 | 363 |
| 동시에 누르는 최대 건반 수 | 3 | 5 |
| 3음 이상 겹치는 길이(박) | 4.00 | 100.50 |
| 서로 다른 왼손 리듬 패턴 | 3 | 4 |

양손의 실제 지속 음을 기준으로 한 손의 동시 도달 범위를 12반음 이내로 제한했습니다. 양손이 같은 물리 건반을 겹쳐 누르는 경우와 음표/MIDI 불일치는 검사에서 발견되지 않았습니다. 이는 기계적 검사이며 실제 연주자의 운지 평가를 대신하지 않습니다.

## 모델 재설계

새 이름공간 `omr.piano_rich`의 자기회귀 Transformer이며 실제 네트워크 클래스는 `omr.models.melody_transformer.MelodyTransformer`, 체크포인트 형식은 `omr-rich-piano-checkpoint-v1`입니다. 기존 `piano_music` 모델 파일과 호환성 해시는 변경하지 않았습니다.

- 어휘 715개. 마디 길이·음표 밀도·동시 발음 수·반주 형태·장단조 조건을 입력합니다. 이 조건은 원본 음표에서 계산한 약한 설명자이며 사람이 정답을 단 장르·감정 라벨은 아닙니다.
- 음표 표현은 위치·길이·역할·새 타건/지속·음높이·속도입니다. 원본의 보표·성부 정보가 있으면 사용하고, 없는 기존 자료는 기하적 역할 추정과 `ATTACK_unknown`을 사용합니다. 보표를 실제 손가락/손 배정 정답으로 간주하지 않습니다.
- 마디 조건 헤더, 악보 인쇄용 고정 velocity, 근거 없는 unknown 타건 라벨은 손실에서 제외합니다. 속도/터치 표현을 악보의 고정 음량으로부터 배웠다고 주장하지 않습니다.
- 폭 256, 6개 레이어, 8개 헤드, FFN1024, 윈도 최대 2,048토큰, 윈도 경계에서 이전 최대4마디 문맥 중첩, dropout0.1, 파라미터 5,629,440개입니다.
- AdamW, 학습률0.0003, weight decay0.01, batch24, seed20261029, bf16을 사용했습니다. 외부 음악 사전학습 가중치는 사용하지 않았습니다.

## 수집·권리·중복·분할

| 원본 자료군 | 최종 파일 수 |
|---|---:|
| mutopia | 459 |
| asap | 141 |
| dcml | 615 |
| nifc | 579 |
| humdrum | 38 |

기존 Mutopia·ASAP·DCML 자료에 NIFC 폴란드/쇼팽 악보와 Sapp Joplin/Haydn 소스를 추가했습니다. NIFC 인코딩의 CC BY4.0과 Sapp 인코딩의 CC BY-NC-SA4.0 및 각 원본의 저작자 표시를 개별 레코드에 보존했습니다. 기존 자료도 파일별 권리 정보가 유지됩니다. 혼합 학습 산출물은 프로젝트 정책상 연구·비상업용 프로필입니다. NIFC의 상업 호환 자료 프로필을 전체 모델의 상업 사용 허가로 확대 해석하지 않았습니다.

후보 9,502개 → 수집기 1차 채택907개 → 변환882개 → 엄격한 입력검사651개 → 중복제거646개 → 추가 타이밍·다중보표·연주편성 검사 후 최종617개가 추가됐습니다. 이 모델은 `input-snapshot-v1`을 사용합니다. 이후 Claude가 확정한 정제본636개와도 다시 대조하여, 최종 코퍼스의 신규617개가 모두 포함되고 음표·보표·붙임줄 내용이 정확히 같은 것을 확인했습니다. 사용하지 않은19개나 다운로드 후보를 학습량에 포함하지 않았습니다.

붙임줄의 출발음을 확인할 수 없는 자료, 불완전 성부 시간, 서로 다른 시간의 보표 병합, 쉼표 없는 성부 공백, 길이가 섞인 모호한 화음, 음높이 없는 임시 토큰, 빈 작곡가 정보, 3개 이상 보표 정체성, 의심되는 2대 피아노/4손 파트를 보수적으로 제외했습니다. 음표는 4분음표당12틱으로 양자화했고, 잔차·장식음 제외·동일 건반 재타건 처리 수를 변환 감사에 기록했습니다. 원본의 모든 미세 타이밍과 장식음을 보존했다고 주장하지 않습니다.

작품/악장/판본·조옮김·정규화 음표 지문을 검사했습니다. 기존 작곡가의 학습/검증/평가 분할을 고정하고 새 작곡가 그룹만 결정적으로 분할했습니다. 학습 1,403개(1,955,465음표), 검증 199개, 평가 230개입니다. 신규617개 중 실제 학습은537개, 검증69개, 평가11개입니다. 원래 쇼팽 그룹은 검증용이므로 추가 쇼팽 자료를 학습에 노출했다고 세지 않았습니다.

주요 신규 출처: [NIFC Polish scores](https://github.com/pl-wnifc/humdrum-polish-scores), [NIFC Chopin first editions](https://github.com/pl-wnifc/humdrum-chopin-first-editions), [Sapp Joplin](https://github.com/craigsapp/joplin), [Sapp Haydn](https://github.com/craigsapp/haydn-piano-sonatas). 정확한 커밋·원본 SHA256·출처 URL·거절 이유는 동봉한 감사 파일과 데이터 레코드에 있습니다.

## 실제 GPU 학습 결과

DGX GB10, PyTorch2.10 계열 NVIDIA 컨테이너, CUDA13, bf16에서 실행했습니다. 정확한 환경은 `training/environment.json`을 기준으로 합니다. 각 에포크가 전체 학습 파일과 대상 토큰을 순회했는지 실행 중 불변식과 완료 로그로 확인했습니다.

|---:|---:|---:|---:|---:|---:|
| 1 | 1,403 | 9,061 | 8,549,642 | 2.1403 | 1.8201 |
| 2 | 1,403 | 9,061 | 8,549,642 | 1.5686 | 1.3559 |
| 3 | 1,403 | 9,061 | 8,549,642 | 1.2334 | 1.0270 |
| 4 | 1,403 | 9,061 | 8,549,642 | 1.0068 | 0.8702 |
| 5 | 1,403 | 9,061 | 8,549,642 | 0.8796 | 0.7660 |
| 6 | 1,403 | 9,061 | 8,549,642 | 0.7908 | 0.6879 |

검증 손실로 선택한 에포크는 6입니다. 평가 손실은 0.8714, 음높이 토큰 정확도는 26.2887%입니다. 문맥을 제거한 동일 대상 평가 손실은 1.0877입니다. 이 수치는 다음 음표 예측 평가이며 청취 선호도, 작곡 완성도 또는 전문가 수준을 보장하는 점수는 아닙니다. 총 실행 시간은 46.96분, optimizer step은 2,268입니다.

타건 분류의 검증 정확도 98.9834%는 새 타건 84,221개·지속 865개의 다수 클래스 기준 98.9834%와 같습니다. 이 수치로 붙임줄·지속 타건 생성 능력이 학습됐다고 판단하지 않았습니다. 이번 구체 편곡은 새 타건을 표기하고 별도의 페달 규칙을 적용했습니다.

초기 music21 변환의 붙임줄·음높이·보표 오류가 독립 대조에서 발견되어, 먼저 수행한 3에포크 실험은 격리했습니다. 그 모델은 최종 모델이나 초기 가중치로 사용하지 않았습니다. 최종 6에포크는 수정한 코퍼스에서 처음부터 수행한 별도 실행입니다.

## 피아노 음색과 재생

Alexander Holm의 [Salamander Grand Piano](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html) Yamaha C5 샘플 SF2(CC BY3.0)를 사용했습니다. 피아노 한 종류만 사용하며 다른 악기·패드·드럼·보컬은 추가하지 않았습니다. 건반 터치의 작은 시차·음량 변화와 CC64 페달은 명시적으로 작성한 연주 처리이며, 악보 그대로의 MIDI와 구분했습니다. 작은 실내 잔향 및 -19LUFS 목표의 동일 음량 처리로 기존 편곡과 비교할 수 있게 했습니다.

새 음원의 길이는 112.823초(잔향 꼬리 포함), 44.1kHz 스테레오이며, master WAV의 클리핑 샘플은 0개입니다. MP3의 음높이는 악보와 같지만 연주용 MIDI의 미세 타이밍·음량·페달이 반영됩니다. 완전한 기계적 재생을 원하면 `score.mid`를 사용하면 됩니다.

SoundFont SHA256: `712d0e681efbe5203a8014e9b3e84168f1908c82f2f6fb13bd2c77d6d72c70b7`. 원본 대형 음원 은행은 압축 패키지/Git에 포함하지 않았습니다. 크레디트·링크·라이선스는 보존했습니다.

## Claude와의 실제 협업 및 검증

Codex가 모델/손실/학습기, 데이터 통합과 GPU 실행, 제약 편곡, MIDI·음원·악보 검증을 담당했습니다. Orca의 실제 Claude Code 작업자가 공개 자료 수집·커밋 고정·권리/작곡가/판본 심사·Kern 파서·원본 대조를 담당했습니다. Claude가 발견한 초기 변환 오류를 반영해 실험을 폐기하고 최종 학습을 다시 진행했습니다. 별도 독립 코드 리뷰가 물리적인 왼손 도달 범위, 타건 플래그 형식, 불명확한 성부 시간과 작곡가 문제를 확인했습니다. 12개 작은 원본 형식 회귀 예제를 추가했습니다. 상세 테스트 결과는 `verification.json`에 있습니다.

제공된 YouTube 링크는 접근 제한으로 직접 청취하지 못했습니다. 영상과의 직접 청취 비교·채보·복제 또는 유사도 달성을 주장하지 않습니다. 원래 이미지의 화면/메모에 담긴 개인 정보는 복사하거나 배포하지 않았습니다.
