## 구현과 실제 학습

장면 설명과 명시적 스타일 선택에서 곡 계획을 만들고, 신선한 가중치의 causal Transformer가 한 마디 안의 성부를 순서대로 생성한다.
앞서 생성한 보컬/반주가 뒤 성부의 문맥에 들어간다. 학습과 추론은 4/4, 1/12박(quarter) 격자의 정확한 Fraction 시간을 사용한다.
표현할 수 없는 분수는 반올림하지 않고 거절한다. 셋잇단음표, 16분음표, 쉼표, 동시발음은 지원한다.

- 제어 프리셋: `kpop_dance`, `kpop_acoustic`, `pop`, `rap`, `ballad`, `rnb`.
- 성부: 보컬, 피아노 오른손/왼손, 베이스, 드럼.
- 계획: 인트로·절·프리코러스·후렴·랩·브리지·아웃트로, 화음, 템포, 그루브, 질감, 밀도.
- 가사: 완전한 프로젝트 원작 문장을 음절 수에 맞게 공급하고, 어절의 begin/middle/end를 악보에 보존한다. 학습된 가사 의미/운율 모델은 아니다.
- 랩: 무음고 리듬 음표와 가사. MIDI에는 `not sung`이라고 명시한 우드블록 리듬 가이드가 있으며 실제 랩 보컬을 합성하지 않는다.
- 후렴: 계획에 따른 이전 보컬 훅 재사용. 재사용 토큰을 먼저 문맥에 넣고 반주를 생성한다.

장면/분위기→계획, 가사 선택, 마디 문법, 음역·화음 제한과 훅 재사용은 명시적 규칙이다.
새로 학습한 것은 공급된 조건과 앞 성부에 대한 음표 위치·길이·음높이·강약의 다음 토큰 분포다.
구조 유효성이나 후렴 반복을 모델이 스스로 배웠다는 주장으로 바꾸지 않는다.
