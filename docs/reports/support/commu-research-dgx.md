# ComMU 추가 연구 전용 통합 학습 — 2026-10-28

사용자는 별도 연구 모델을 추가하는 2번 선택을 하고 계속 진행하도록 요청했다. 기존 상용 가능 자료 정책 기반 모델과 데이터는 그대로 보존했으며, 아래 연구 모델은 새 가중치와 별도 저장 경로를 사용했다. **연구 모델·연구 예제는 비상업적 연구 전용으로 관리한다.** ComMU 원자료는 [공식 저장소](https://github.com/pozalabs/ComMU-code#license)에 따라 CC BY-NC-SA 4.0이다. 저장소의 MIT 코드 라이선스와 데이터 라이선스를 구분한다.

## 실제 데이터와 조건

공식 ComMU 원본 창작 MIDI 11,144개와 메타데이터를 확보했다. 증강 파일이나 제공된 사전 학습 가중치를 사용하지 않았다. 원 MIDI는 모두 program 0으로 저장되어 있어 실제 악기 정보는 별도 메타데이터의 38개 기본 악기명에서 읽었다. 130개 이름의 `-N` 표시는 변형 식별자로 보존하고 표준 GM 대표 악기로 대응했다. 이 대응은 원음색을 복원했다는 뜻이 아니다. 원자료·매핑·해시는 제공한 manifest와 Claude의 감사 문서에 있다.

원래 라벨은 cinematic 8,024개와 newage 3,120개다. 역할은 주선율·반주·보조선율·패드·리프·베이스이며, 원래 조성은 C장조와 A단조다. 현대 케이팝·팝·랩 보컬 선율 자료로 바꾸어 부르지 않는다.

역할·조성·마디 화음의 조건을 추가한 `omr-real-partbar-research-v1` 토크나이저를 Claude와 구현했다. 기본 8개 접두부에 ROLE/KEY/CHORD 3개 조건을 더해 11개를 학습 손실에서 제외하고 음표를 예측한다. 한 마디 안에서 화음이 바뀌면 순서대로 중복을 제외한 `C>G` 같은 조건을 기록한다. 마디 수와 화음 격자가 명확히 대응되지 않는 경우에는 추측 대신 unknown을 주며 음표 학습은 유지한다.

중복된 동일 문맥 9개를 제외한 ComMU 11,135개를 기존 실제 자료 6,109개와 합쳤다. 연구 데이터는 총 **17,244개 실제 파일, 853,772개 관측 파트 마디, 5,280,382개 음표**다. 절차적 합성·조옮김 증강 자료는 0개다.

## 평가 분리

공식 validation 763개 중 755개가 학습 자료와 화음 진행·조성·템포 등의 바탕 그룹을 공유했다. 이를 그대로 두고 새로운 곡에 대한 일반화로 주장하지 않기 위해 414개 메타데이터 바탕 그룹을 상대 음높이·리듬 지문과 합쳐 304개 그룹으로 만들고, 스타일·분량에 따라 통째로 분리했다. 공식 split은 추적용으로 보존한다. 이는 바탕 그룹의 대용 지표이며 실제 작곡가나 완성곡 ID를 제공받은 것은 아니다. 원래 공식 split 평가와 직접 비교하지 않는다.

기존 기본 모델 자료의 분리는 바꾸지 않았다. ComMU는 학습 65,016개, 검증 8,130개, 최종 평가 8,140개의 파트 마디다. 전체 연구 학습은 실제 파일 **13,555개**, 학습열 **682,325개**를 3회 모두 순회해 총 2,046,975회 제시했다. 전체 검증 81,234개와 최종 평가 90,213개는 학습에 사용하지 않았다. 분리를 넘나드는 그룹은 0개다.

## 분리·생성·한계

기본 학습 프로필은 NC 자료를 거부한다. 연구 체크포인트는 `load_checkpoint(..., allow_research=True)` 또는 CLI `--allow-research-model`을 명시해야 읽을 수 있다. 현재 코드도 이전 기본 체크포인트를 정상 로드하며 기본 파일 해시 `eec69a2f...`와 원 manifest `30ca4072...`는 그대로다. 새 연구 토크나이저는 별도 파일이고 기본 토크나이저·Transformer 구현은 변경하지 않았다.

연구 예제 8개는 피아노 주선율·반주, 현악 패드, 더블베이스, 어쿠스틱 기타 리프, 플루트 보조선율을 실제 학습된 문맥으로 생성했다. 8마디의 반복 4화음 계획은 명시적 편곡 선택이며 장면 해석을 학습했다는 뜻이 아니다. 피아노는 실제 사용된 손 보표만 만들고 악기 표시는 음색 대표 프로그램에 맞췄다. 정확한 모델 이벤트와 읽기 쉬운 표기본을 함께 보존한다. 전 예제의 XML/MIDI 음높이·길이·강세·파트 마디를 대조한다.

가사나 사진-분위기-음악 정답쌍은 이번 모델의 학습 대상이 아니다. 사용자가 제공한 MP4는 창작 참조물로 보존했고 정렬된 악보 정답으로 사용하지 않았다. 모델은 관측 파트 마디를 예측하며 전체 합주 관계·노랫말 의미·장기 곡 구조의 완성도를 검증한 상용 작곡 시스템은 아니다. 연구 예제와 기본 예제의 이용 조건은 각 패키지 README에서 확인할 수 있다.
